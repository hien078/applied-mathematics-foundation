## Overview

Graph theory provides the mathematical language for describing relationships between discrete objects. Graphs model everything from social networks and transportation systems to molecular structures and neural architectures. This foundation covers the essential definitions, representations, properties, and algorithms needed for mathematical modeling on networks.

---

## Learning Objectives

After completing this foundation, you should be able to:

1. **Define and classify graphs** — distinguish directed/undirected, weighted/unweighted, simple/multi graphs
2. **Represent graphs mathematically** — construct adjacency matrices, adjacency lists, and incidence matrices
3. **Analyze graph properties** — compute degree sequences, identify connectivity, find paths and cycles
4. **Understand trees** — recognize tree structures, compute spanning trees, apply minimum spanning tree algorithms
5. **Apply graph algorithms** — implement BFS, DFS, and Dijkstra's shortest path
6. **Identify special graph classes** — bipartite, complete, planar, Eulerian, and Hamiltonian graphs
7. **Connect to modeling** — recognize when a real-world problem has graph structure

## Connection to Modeling

Graph theory is the essential prerequisite for:

- **Network flow models** — transportation, supply chains, max-flow/min-cut
- **Social network analysis** — centrality, clustering, community detection
- **Epidemiological models on networks** — SIR on graphs, contact tracing
- **Graph Neural Networks (GNNs)** — message passing, node classification, link prediction
- **Optimization on graphs** — shortest paths, traveling salesman, graph coloring
