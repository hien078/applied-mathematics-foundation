# Mathematics for Machine Learning from Scratch 🧮

[![Python 3.12+](https://img.shields.io/badge/python-3.12+-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Jupyter](https://img.shields.io/badge/Jupyter-Lab-orange.svg)](https://jupyter.org/)
[![NumPy](https://img.shields.io/badge/NumPy-2.4+-blue.svg)](https://numpy.org/)

First-principles mathematical foundations for machine learning. Rigorous derivations, geometric intuition, and NumPy-verified implementations for **Linear Algebra**, **Calculus & Optimization**, **Probability & Statistics**, **Information Theory**, and **Numerical Computing**.

> 📌 **Sister Repository:** Applied algorithm implementations and full ML model pipelines are available in [Machine-Learning-from-scratch](https://github.com/hien078/Machine-Learning-from-scratch).

---

## 🏛️ Mathematical Pillars

| Pillar | Module Folder | Key Topics Covered |
|---|---|---|
| 📐 **Linear Algebra** | [`linear_algebra/`](linear_algebra/README.md) | Vectors & Matrices, Norms & Distances, Projections & Least Squares, Eigenvalues & SVD |
| 📈 **Calculus & Optimization** | [`calculus_optimization/`](calculus_optimization/README.md) | Derivatives & Gradients, Taylor Approximation, Gradient Descent Mechanics, Optimization Landscapes |
| 🎲 **Probability & Statistics** | [`probability_statistics/`](probability_statistics/README.md) | Probability Basics, Random Variables & Distributions, Expectation & Variance, Maximum Likelihood Estimation (MLE) |
| 📊 **Information Theory** | [`information_theory/`](information_theory/README.md) | Entropy, Cross-Entropy, KL Divergence, Mutual Information |
| 💻 **Numerical Computing** | [`numerical_computing/`](numerical_computing/README.md) | Floating-Point Stability, Conditioning & Ill-Posed Problems, Vectorization in NumPy |

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/hien078/Mathematics-for-ML-from-scratch.git
cd Mathematics-for-ML-from-scratch
```

### 2. Set Up Environment
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Launch JupyterLab
```bash
jupyter lab
```
